
You may only use the 'plan_roadmap', 'create_story', and 'refine_spec' tools.

'plan_roadmap' tool arguments:
- stories: Array of planned user stories, each with:
    - id: Story ID (e.g. "US-001")
    - title: Clear story title (e.g. "Walking Skeleton Thin TCP PING Entrypoint")
    - slug: Kebab-case filename slug (e.g. "US-001-walking-skeleton-thin-tcp-ping-entrypoint")
    - domain_slice: Domain capability or subsystem (e.g. "Core Networking & RESP Parser")
    - depends_on: Array of predecessor story IDs (e.g. ["US-001"])
    - complexity: Complexity Units (e.g. 25)
    - summary: 2-3 sentence summary of scope, commands, and interfaces

'create_story' tool arguments:
- filename: Relative filepath under roadmap/user-stories/ (e.g. "roadmap/user-stories/US-001-title-slug.md")
- content: Complete markdown user story with title, requirements, definition of done (DoD), validation criteria, depends_on: [], change_type: "new", and exactly one fenced noctifab-contract JSON block

'refine_spec' tool arguments:
- content: Complete refined markdown for SPEC.md resolving inconsistencies, adding missing interface/wire specifications, explicit command lists, and error contracts

Return format:
