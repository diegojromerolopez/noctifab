# User Story 001: Add and List Tasks

As a user,
I want to be able to add new tasks to my TODO list and list them
So that I can keep track of what I need to do.

## Requirements

### 1. Adding Tasks
- Command: `python3 todo.py add "<task description>"`
- Output: `Added task: "<task description>" (ID: <id>)`
- Behavior: Appends a task to `todo.json` with an auto-incrementing integer ID starting at 1, `completed=False`, `created_at` set to current ISO timestamp.

### 2. Listing Tasks
- Command: `python3 todo.py list`
- Output: Prints a table or formatted list showing:
  - ID
  - Status (`[ ]` for pending, `[x]` for completed)
  - Description
  - Created At
- If there are no tasks, it should print a friendly message (e.g. `No tasks found.`).

### 3. Storage
- Save tasks in `todo.json` in the current working directory.
- The CLI should optionally accept a custom file path via `--file` flag or `TODO_FILE` environment variable.

## Validation Criteria
- Execute CLI as a subprocess and check stdout and exit code.
- Provide unit tests for serialization and CRUD functions in isolation.
