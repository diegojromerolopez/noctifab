# User Story 002: Complete and Remove Tasks

As a user,
I want to mark tasks as completed or delete them
So that I can keep my list updated and clean.

## Requirements

### 1. Completing Tasks
- Command: `python3 todo.py done <id>`
- Output: `Task <id> marked as completed.`
- Behavior: Updates the task with the given ID to `completed=True` and sets `completed_at` to the current ISO timestamp in `todo.json`.
- Error Case: If the ID does not exist, print an error to `stderr` and exit with exit code 1.

### 2. Removing Tasks
- Command: `python3 todo.py rm <id>`
- Output: `Task <id> removed.`
- Behavior: Deletes the task with the given ID from `todo.json`.
- Error Case: If the ID does not exist, print an error to `stderr` and exit with exit code 1.

## Validation Criteria
- Verify that done/rm commands update the database properly.
- Handle non-existent IDs gracefully by writing to stderr and returning a non-zero exit code.
