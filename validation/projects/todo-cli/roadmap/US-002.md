# User Story 002: Complete and Remove Tasks

As a user,
I want to mark tasks as completed or delete them
So that I can keep my list updated and clean.

## Requirements

### 1. Completing Tasks
- Command: `todo done <id>` (binary invocation form per US-001).
- Output: `Task <id> marked as completed.`
- Behavior: Updates the task with the given ID to `Completed=True` and sets `CompletedAt` to the current ISO timestamp (RFC3339-UTC, `Z` suffix) in `todo.json`.
- Idempotency: `done` on an already-completed task is a no-op that still prints `Task <id> marked as completed.` and exits 0 (`completed_at` is NOT re-stamped).
- Error cases:
  - Missing id: `todo: task not found: <id>` to stderr, exit 1.
  - Non-integer `<id>` (e.g. `done abc`): `todo: invalid id: abc` to stderr, exit 1.
  - No arg (`done`): `todo: missing task id` to stderr, exit 2.
- The `done` command honors `--file`/`TODO_FILE` as in US-001.

### 2. Removing Tasks
- Command: `todo rm <id>`
- Output: `Task <id> removed.`
- Behavior: Deletes the task with the given ID from `todo.json`. `rm` does NOT reindex remaining IDs; the next `add` uses `max(remaining IDs) + 1` (per SPEC §2.4).
- Error cases (mirrors `done`):
  - Missing id: `todo: task not found: <id>` to stderr, exit 1.
  - Non-integer `<id>`: `todo: invalid id: <input>` to stderr, exit 1.
  - No arg: `todo: missing task id` to stderr, exit 2.
- Honors `--file`/`TODO_FILE`.

## Architectural & Performance Constraints
- DI preserved; `done`/`rm` CLI handlers accept an injected `Repository` (no global state).
- Performance: < 100 ms wall-clock for a 10,000-task file.

## Validation Criteria

### Unit Tests (internal/...)
- Fake-repo `done_test`/`rm_test` assert exact stdout, exit codes for missing id (1), non-integer id (1), no arg (2), already-completed idempotent path (exit 0).
- `jsonrepo_test` (extend): `MarkCompleted` sets `Completed=true` and `CompletedAt=clock.Now()` exactly once and is idempotent; `Delete` removes by id leaving other ids unchanged; both error with `task.ErrNotFound` for unknown id.

### Integration Tests (tests/)
- Tempdir, build binary, seed `todo.json` with 3 tasks, run `done 2`, assert stdout `Task 2 marked as completed.` + exit 0, assert file shows task 2 `completed=true` and `completed_at` set.
- Run `rm 1`, assert stdout `Task 1 removed.` + exit 0, assert file contains tasks [2,3] with ids unchanged.
- Run `done 99` → exit 1, stderr `todo: task not found: 99`.
- Run `rm abc` → exit 1, stderr `todo: invalid id: abc`.
- Run `done` (no arg) → exit 2, stderr `todo: missing task id`.
- Idempotency: run `done 2` twice; second run still prints `Task 2 marked as completed.` and exit 0; `completed_at` unchanged.
